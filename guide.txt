d : corresponds to the delete operator. Since d is an operator, you can follow the {operator}{count}{motion} formula and combine it with all the motions you’ve learned thus far:

d5j : to delete 5 lines downwards
df' : to delete everything in the current line from the cursor until the first occurrence of the ' character (including the character itself)
Or type dt' to do like the above example but excluding the character (so up until or just before the ' character)
Use d/hello to delete everything until the first occurrence of hello
Type ggdG to delete a complete document

Registers

Registers in Vim let you run actions or commands on text stored within them. To access a register, you type "a before a command, where a is the name of a register. If you want to copy the current line into register k, you can type
"kyy
Or you can append to a register by using a capital letter
"Kyy
You can then move through the document and paste it elsewhere using
"kp
To paste from system clipboard on Linux
"+p
To paste from system clipboard on Windows (or from "mouse highlight" clipboard on Linux)
"*p
To access all currently defined registers type
:reg




I was pleased when I discovered the 0 register. If you yank text without assigning it to a particular register, then it will be assigned to the 0 register, as well as being saved in the default " register. The difference between the 0 and " registers is that 0 is only populated with yanked text, whereas the default register is also populated with text deleted using d/D/x/X/c/C/s/S commands.
I find this useful when I want to copy some text, delete something and replace it with the copied text. The following steps illustrate an example:
Yank the text you want to copy with y[motion] - this text is saved in " and 0 registers
Delete the text you want to replace with d[motion] - this text is saved in " register
Paste the yanked text with "0p
where " is the command to use a register for the next command.
On the final step, if you were to paste from the default register (with p), it would use the text that you had just deleted (probably not what you intended).
Note that p or P pastes from the default register. The longhand equivalent would be ""p (or ""P) and "0 holds the last yank, "1holds the last delete or change.

========================
NEOVIM CHEATSHEET (FINAL SETUP)
========================

========================
SEARCH / NAVIGATION (Telescope)
========================
<leader>ff   Find files in project
<leader>fg   Search text across codebase (grep)
<leader>fb   Open buffers (recent files)
<leader>fh   Search help/docs

========================
FILE EXPLORER (nvim-tree)
========================
<leader>e    Toggle file tree sidebar
<leader>ef   Focus file tree
<leader>er   Reveal current file in tree

INSIDE TREE
a → add file/folder
r → rename
d → delete
Enter → open file

========================
CODE NAVIGATION (LSP)
========================
gd           Go to definition
gr           Find references (usage of symbol)
K            Hover docs / type info

========================
HISTORY NAVIGATION (IMPORTANT)
========================
Ctrl+o       Go back (previous location/jump stack)
Ctrl+i       Go forward

NOTE:
- Works after gd, gr, search, file jumps

========================
ERROR NAVIGATION
========================
[d           Previous error
]d           Next error
<leader>d    Show error popup details

========================
REFACTOR / CODE ACTIONS
========================
<leader>rn   Rename symbol across project
<leader>ca   Code actions (fix imports/refactor)
<leader>f    Format file

========================
TERMINAL (toggleterm)
========================
<leader>t    Toggle terminal open/close

INSIDE TERMINAL:
Ctrl+\ Ctrl+n   Exit terminal mode → back to Neovim

NOTE:
- You must exit terminal mode before moving windows

========================
WINDOW SPLITS
========================
:vs          Vertical split (left/right)
:sp          Horizontal split (top/bottom)

MOVE BETWEEN SPLITS:
Ctrl+w h     Left window
Ctrl+w l     Right window
Ctrl+w j     Down window
Ctrl+w k     Up window

WINDOW ACTIONS:
Ctrl+w c     Close current split
Ctrl+w o     Close all others (focus one)
Ctrl+w =     Equalize window sizes

========================
Telescope SPLIT OPENING
========================
Ctrl+v       Open file in vertical split
Ctrl+x       Open file in horizontal split
Enter        Open normally (replace window)

========================
SEARCH IN FILE
========================
/pattern     Search forward
n            Next match
N            Previous match

========================
BASIC EDITING
========================
gg           Top of file
G            Bottom of file
dd           Delete line
yy           Copy line
p            Paste
u            Undo
Ctrl+r       Redo

========================
THEME SWITCHING (Themery)

:bp                Previous buffer
:bdelete           Close current buffer

NOTE:
Buffers = all open files in memory (core Neovim model)
